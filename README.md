# Clustering---Review-Stardew-Valley-from-Steam-Web
Proyek ini membahas proses pengolahan dan analisis data ulasan pengguna game Stardew Valley yang diperoleh dari platform Steam. Analisis dilakukan melalui Unsupervised Learning menggunakan Hierarchical Clustering dan Non-Hierarchical Clustering, serta Supervised Learning menggunakan algoritma Random Forest
